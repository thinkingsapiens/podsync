A native app for macOS, Windows, and Linux. Syncs your subscriptions and play state with gpodder.net, works fully offline, and skips ads using an on-device model. Nothing ever leaves your device.

gpodder.net sync

Subscriptions and play state stay in sync across every gpodder.net-connected client you use, resumable after any outage.

Menu bar mini player

Close the window and keep listening from a compact tray player, without the app taking up Dock space.

Native on every platform

A small download that starts fast and stays light on battery and memory, even left running in the background all day, on macOS, Windows, or Linux.

Self-updating

PodSync checks for new versions and can update itself in place, so you're never stuck manually tracking releases.

On-device transcripts

Every episode gets a full transcript, generated on your Mac. Nothing is uploaded, and there's no per-minute API bill.

Follow along while it plays

FAQ

What platforms does PodSync run on?

PodSync is a native app for macOS (Apple Silicon and Intel), Windows, and Linux, with a small install size and low idle resource use on every platform.

How do I log in, and which sync providers does it support?

Sign in with your existing gpodder.net account, or a self-hosted, API-compatible gpodder server. That's the only sync provider PodSync talks to: there's no separate PodSync account or cloud backend. Your local SQLite library is the source of truth; gpodder.net is a sync target the app reconciles subscriptions and play state with whenever you're online.

What does gpodder.net sync actually keep in sync?

Subscriptions and play state (what you've played and where you left off), shared across every gpodder.net-connected client you use, PodSync included. Sync is resumable after an outage or crash, so it's safe to go offline and come back later.

Does PodSync skip ads automatically?

PodSync detects ads in episodes using a local on-device model by default, so nothing is uploaded for this to work. Detected ads can be auto-skipped, currently an experimental feature. If you'd rather use a remote model instead of the on-device one, you can connect your own OpenAI-compatible LLM API, in which case only that provider sees the transcript.

Is my listening data private?

Yes. Ad detection and episode transcription run entirely on your Mac by default, and nothing about what you listen to is sent anywhere for those features to work. gpodder.net only ever sees subscriptions and play state, which is what it's for.

How do I install PodSync on Windows or Linux?

Grab the installer for your platform from the releases page: a .exe on Windows, or a .deb, .rpm, or .AppImage on Linux.

On macOS or Linux you can instead run the install script, which downloads the right build for your platform and installs it:

/bin/bash -c "$(curl -fsSL https://thinkingsapiens.github.io/podsync/install.sh)"

You can read the script before running it. Homebrew (brew install thinkingsapiens/podsync/podsync-app) is macOS-only. PodSync updates itself in place once installed, on every platform.

Is PodSync free?

Free during the alpha/beta testing period. See the changelog for what's shipped so far.
