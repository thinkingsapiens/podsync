PodSync v0.1.0-alpha.1

August 19, 2026

First alpha build — free during testing.

Features
- gpodder.net login & sync (subscriptions and play state)
- Offline-first local library (SQLite) — works without a connection
- Podcast search (iTunes + optional Podcast Index API)
- Episode downloads with a download manager
- Artwork caching
- Full episode transcripts (on-device Whisper)
- Ad detection — fully on-device by default (nothing leaves your Mac), or bring your own OpenAI-compatible remote LLM API instead
- Experimental auto-skip for detected ads
- Menu bar mini player
- Light/dark/system theme, follows macOS appearance
- Self-updating via this release pipeline

macOS 11+, Apple Silicon only. Not notarized yet — see the Docs page for the one-time Gatekeeper workaround.
