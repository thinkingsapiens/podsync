PodSync v0.1.0-alpha.2

August 20, 2026

What's new since alpha.1

  • New "In Progress" sidebar filter for episodes you've started but not finished, separate from "Unplayed"
  • Episode list can now sort oldest-first or newest-first
  • Redesigned skip-back/skip-forward buttons — a circular-arrow icon showing the actual skip amount (30s), instead of icons that read as track-skip controls
  • New "Remove from In Progress" action to reset an episode's progress without marking it played
  • Sidebar now clearly highlights the selected item — previously indistinguishable from a plain hover
  • Ad detection: no longer silently falls back to the on-device model when the remote engine is enabled but misconfigured — fails clearly with a toast instead; "Re-detect ads" now genuinely re-runs detection instead of silently no-op'ing; detection can now be stopped mid-run
  • Assorted UI fixes: episode detail action buttons wrap instead of overflowing on a narrow pane, waveform detect-ads button no longer glitches its label while spinning

Full Changelog: https://github.com/thinkingsapiens/podsync/commits/v0.1.0-alpha.2

PodSync v0.1.0-alpha.1

August 19, 2026

First alpha build — free during testing.

Features

  • gpodder.net login & sync (subscriptions and play state)
  • Offline-first local library (SQLite) — works without a connection
  • Podcast search (iTunes + optional Podcast Index API)
  • Episode downloads with a download manager
  • Artwork caching
  • Full episode transcripts (on-device Whisper)
  • Ad detection — fully on-device by default (nothing leaves your Mac), or bring your own OpenAI-compatible remote LLM API instead
  • Experimental auto-skip for detected ads
  • Menu bar mini player
  • Light/dark/system theme, follows macOS appearance
  • Self-updating via this release pipeline

macOS 11+, Apple Silicon only. Not notarized yet — see the Docs page for the one-time Gatekeeper workaround.
