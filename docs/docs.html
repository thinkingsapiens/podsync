Docs & FAQ

Fastest install: paste one command into Terminal, about two minutes. Everything below that is reference.

System requirements

  • macOS 11 (Big Sur) or later
  • Apple Silicon (M1 or newer). There is currently no Intel build

Installing

Install script

Downloads the latest release and copies PodSync into /Applications. You don't need Homebrew. If you've never opened Terminal, here is the whole thing:

  1. Open Terminal. In Finder it's under Applications → Utilities → Terminal, so double-click it there. (Faster: press ⌘Space, type terminal, press Return.) You get a window with one line of text and a blinking cursor. That's the prompt, and it's waiting for you.
  2. Copy the command below using its Copy button.
/bin/bash -c "$(curl -fsSL https://thinkingsapiens.github.io/podsync/install.sh)"
  1. Click the Terminal window, press ⌘V to paste the command, then press Return to run it.
  2. Wait. A progress bar fills while the 13 MB download runs, and the last line tells you which version it installed. It never asks for your password.
  3. Quit Terminal and open PodSync from your Applications folder.

Pasting a command you can't read is a fair thing to be wary of, so read the script first if you want. It's plain text. Quit PodSync before you run it if the app is already open. When it replaces an existing install, it moves the old copy to the Trash instead of deleting it.

Homebrew

If you already use Homebrew, this installs the same build and follows new releases, so brew upgrade keeps you current. Paste it into Terminal the same way and press Return. 

brew install thinkingsapiens/podsync/podsync-app

Manual download

Download the latest .dmg from the Releases page, open it, and drag PodSync into Applications.

"PodSync can't be opened because it is from an unidentified developer"

PodSync isn't notarized by Apple yet, so the first launch trips Gatekeeper's unidentified-developer warning. The install script and the Homebrew cask clear this for you. If you installed by hand from the .dmg, you have two options.

  • Right-click PodSync.app in Applications → Open → Open again in the dialog, or
  • Open Terminal (Applications → Utilities → Terminal), paste the command below, press Return, then launch PodSync normally. You only need to do this once: 
xattr -cr /Applications/PodSync.app

This is a one-time step per install. It goes away once notarized builds ship.

How gpodder.net sync works

PodSync stores your library locally in SQLite and treats gpodder.net as a sync target, not a backend. The app works fully offline and reconciles with gpodder.net (subscriptions, play state) whenever you're online. Sign in with your existing gpodder.net account, or a self-hosted, API-compatible server.

Privacy & on-device ad detection

Ad detection and transcription run entirely on your Mac using a local model, so no audio, transcript, or listening data is sent anywhere for this feature. If you connect a remote LLM API for ad detection instead, only that provider sees the transcript, not PodSync's developers.

Updating

PodSync checks for updates automatically and shows a "Check for Updates" control in Settings. When a new version is available you can review the release notes and install it in place, without needing to re-download a .dmg manually.

Source

PodSync's source is closed for now. This repository (thinkingsapiens/podsync) hosts signed releases and this site.
